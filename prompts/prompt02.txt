Структура итогового файла:
1. Краткое введение:
   - как устроен материал;
   - как им пользоваться при подготовке к аттестации.
2. Раздел "Теоретические темы":
   - сгруппируй темы по семестрам;
   - для каждой темы сначала дословно приведи исходную формулировку;
   - затем дай развёрнутый ответ.
3. Раздел "Разбор примерных билетов":
   - для каждого билета дословно приведи его состав;
   - после этого дай полный образец ответа по каждому пункту билета;
   - в конце билета добавь краткий вывод: что особенно важно сказать на защите или устном ответе.
4. Раздел "Практические задания":
   - для каждого задания на разработку программы подготовь воспроизводимое решение для Google Colab.

Формат для теоретической темы:
1. Заголовок темы.
2. Исходная формулировка.
3. Развёрнутый ответ:
   - определение и суть подхода;
   - ключевые компоненты, этапы или архитектурные блоки;
   - преимущества, ограничения и типичные области применения;
   - сравнение с близкими подходами, если это уместно.
4. Краткий список ключевых терминов.
5. Если уместно, предложи короткую идею демонстрации в Google Colab.

Формат для практического задания:
1. Заголовок задания.
2. Исходная формулировка.
3. Краткая идея решения.
4. Какие библиотеки используются и зачем.
5. Готовый код для Google Colab:
   - при необходимости отдельная ячейка установки зависимостей;
   - загрузка или генерация данных;
   - подготовка данных;
   - модель;
   - обучение или демонстрационный запуск;
   - оценка качества, включая IoU для каждого класса, если это требуется в задании.
6. Пояснение, как запустить код и какой результат должен получиться.
7. Ограничения, допущения и как можно улучшить решение.

Дополнительные правила:
- Если исходных данных в задании недостаточно, явно укажи разумные допущения.

- Если нужен датасет, используй доступный учебный вариант, небольшой поднабор, открытый источник или сгенерируй демонстрационные данные.
- Код должен быть цельным, воспроизводимым и пригодным для запуска в Google Colab без ручной доработки.
- Итоговый файл оформи в Markdown с понятной иерархией заголовков.
