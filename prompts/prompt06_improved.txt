## Что нужно сделать

1. Для каждого пункта, начинающегося со слова `Задание`, добавь краткий ответ сразу после формулировки задания.
2. Для каждого пункта, начинающегося со слова `Вопрос`, добавь ответ сразу после формулировки вопроса.
3. Если пункт является теоретическим, дай содержательный, но компактный ответ: определения, ключевые идеи, этапы, преимущества, ограничения.
4. Если пункт является практическим или явно требует разработки алгоритма, программы, эксперимента, обработки данных, оценки качества или сравнения результатов, включи пример на Python.
5. Если пункт является темой реферата и содержит пометку `(тема реферата)`, дай краткое сообщение по теме: актуальность, основные аспекты рассмотрения, возможные выводы.
6. Для практических вопросов дифференцированного зачета и экзамена пример на Python обязателен, если вопрос допускает программную иллюстрацию.
7. Для архитектур нейронных сетей по возможности добавляй схему или изображение в Markdown-формате. Если готового изображения нет, добавь краткое текстовое описание структуры архитектуры без выдуманных ссылок.

**Готовый код для Google Colab.**
```python

```

**Как запустить код и какой результат должен получиться.**
Кратко опиши порядок запуска и ожидаемый результат.

**Ограничения, допущения и возможные улучшения.**
Укажи важные ограничения примера и как его можно развить.

Для темы реферата используй формат:

**Ответ.** Краткое сообщение по теме реферата: предмет рассмотрения, ключевые вопросы, связь с курсом и возможные выводы.

## Требования к коду

- Код должен быть рассчитан на запуск в Google Colab.
- Если нужны внешние библиотеки, добавь установку через `pip` в отдельной строке кода только при реальной необходимости.
- Не используй тяжёлые обучающие примеры, требующие больших датасетов или длительного обучения; вместо этого применяй компактные синтетические данные.
- Для примеров по облакам точек используй небольшие массивы `numpy` или синтетически сгенерированные точки.
- Для примеров по метрикам используй простые вычисления на малых массивах.
- Для примеров по нейросетям допускается демонстрационный код на `numpy`, `scikit-learn`, `torch` или `tensorflow`, но выбирай самый простой вариант для иллюстрации идеи.
- Листинги оформляй компактно: без лишних пустых строк, длинных поясняющих комментариев и повторяющихся фрагментов.

## Требования к формулам и оформлению

- Формулы в теоретических ответах оформляй в LaTeX.
- Встроенные формулы оформляй как `$...$`.
- Отдельные формулы оформляй как `$$...$$`.
- Не вставляй лишние пустые абзацы внутри листингов кода.
- Сохрани Markdown-структуру исходного документа.
- Не добавляй новые разделы, не удаляй существующие разделы и не меняй порядок пунктов.
