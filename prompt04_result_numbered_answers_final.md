Задание 10. Сравнить постановки задач сегментации и детекции двумерной пространственной информации на примере архитектур UNet и YOLO.

Вопрос 16. Как формулируется задача классификации двумерной пространственной информации на основе полносвязных нейронных сетей?

Ответ. Задача формулируется как отображение признакового вектора двумерного объекта или фрагмента изображения в один из классов. Растр или карта признаков преобразуется в вектор $x$, а сеть оценивает вероятности классов $p(y|x)$. Полносвязная сеть подходит для компактных признаков, но хуже учитывает локальную структуру изображения, чем сверточные модели.

В задачах машинного обучения для пространственных данных всегда задаются входное представление, целевая переменная и метрика качества. Классификация возвращает метку объекта или облака, сегментация присваивает класс каждому элементу, а детекция определяет положение объекта и его класс.

Качество решения удобно проверять через accuracy, precision, recall, F1, IoU и mean IoU. Для сегментации ключевая формула имеет вид $IoU = TP/(TP+FP+FN)$, где $TP$ - верно найденные элементы класса, $FP$ - ложные срабатывания, $FN$ - пропущенные элементы.

Вопрос 17. Как архитектура UNet применяется для сегментации пространственной информации, представленной в двумерном виде?

Ответ. UNet решает задачу пиксельной сегментации: каждому пикселю входного изображения сопоставляется класс. Архитектура имеет encoder для извлечения признаков, decoder для восстановления разрешения и skip connections для сохранения деталей. Текстовая схема: `изображение -> encoder -> bottleneck -> decoder + skip connections -> маска`.

UNet используется для плотной сегментации двумерных пространственных данных. Encoder извлекает признаки на разных масштабах, decoder восстанавливает пространственное разрешение, а skip connections возвращают локальные детали, потерянные при сжатии.

Результат UNet - маска того же размера, что и входное изображение. Такая постановка подходит для задач, где важна форма области: выделение объектов, зон интереса, границ или классов пикселей.

Вопрос 18. Как архитектура YOLO применяется для детекции пространственной информации, представленной в двумерном виде?

Ответ. YOLO решает задачу детекции за один проход сети: находит объекты, предсказывает bounding boxes, классы и уверенности. Для двумерной пространственной информации это позволяет быстро определить, где находятся объекты интереса. В отличие от сегментации, результатом является не маска, а набор прямоугольных областей.

YOLO решает задачу детекции объектов за один проход модели. Вместо пиксельной маски он возвращает набор прямоугольных областей, классы и оценки уверенности, что делает подход удобным для быстрой локализации объектов.

В пространственной обработке YOLO применим к двумерным изображениям, растровым картам или проекциям данных. Качество оценивается через IoU bounding boxes, precision, recall и устойчивость к масштабу объектов.

### 4.1. Теоретические вопросы
Вопрос 1. Какие подходы, методы и модели машинного обучения применяются для обработки пространственной информации в трехмерном виде?

Ответ. Для трехмерной пространственной информации применяются модели классификации, сегментации и детекции облаков точек. В курсе выделяются PointNet и PointNet++ для классификации и сегментации, DGCNN для сегментации с учетом графа соседства, VoteNet для детекции объектов, а также методы поверхностной реконструкции для восстановления сеток по первичным точкам.

В задачах машинного обучения для пространственных данных всегда задаются входное представление, целевая переменная и метрика качества. Классификация возвращает метку объекта или облака, сегментация присваивает класс каждому элементу, а детекция определяет положение объекта и его класс.

Качество решения удобно проверять через accuracy, precision, recall, F1, IoU и mean IoU. Для сегментации ключевая формула имеет вид $IoU = TP/(TP+FP+FN)$, где $TP$ - верно найденные элементы класса, $FP$ - ложные срабатывания, $FN$ - пропущенные элементы.

Вопрос 2. Как архитектура PointNet решает задачу классификации пространственной информации, представленной в виде облака точек?

Ответ. PointNet рассматривает облако точек как неупорядоченное множество. Каждая точка проходит через общую MLP-сеть, затем признаки агрегируются симметричной функцией, обычно max pooling, чтобы результат не зависел от порядка точек. Текстовая схема: `points -> shared MLP -> max pooling -> global feature -> classifier`.

PointNet обрабатывает облако точек как неупорядоченное множество. Каждая точка проходит через общие MLP-слои, после чего признаки агрегируются симметричной операцией, обычно max pooling. Благодаря этому результат не зависит от перестановки точек.

Для классификации глобальный признак подается в классификатор всего облака. Для сегментации глобальный контекст объединяется с локальными признаками точек, и модель выдает метку для каждой точки. Текстовая схема: `points -> shared MLP -> max pooling -> global feature -> class/point labels`.

Вопрос 3. Как архитектура PointNet применяется для сегментации пространственной информации в трехмерном виде?

Ответ. Для сегментации PointNet объединяет глобальный признак всего облака с локальными признаками каждой точки и предсказывает метку для каждой точки. Это позволяет учитывать как общий контекст объекта, так и индивидуальное положение точки. Выход имеет размер `N x C`, где `N` - число точек, а `C` - число классов.

PointNet обрабатывает облако точек как неупорядоченное множество. Каждая точка проходит через общие MLP-слои, после чего признаки агрегируются симметричной операцией, обычно max pooling. Благодаря этому результат не зависит от перестановки точек.

Для классификации глобальный признак подается в классификатор всего облака. Для сегментации глобальный контекст объединяется с локальными признаками точек, и модель выдает метку для каждой точки. Текстовая схема: `points -> shared MLP -> max pooling -> global feature -> class/point labels`.

Вопрос 4. Как архитектура PointNet++ используется для сегментации облаков точек и оценки разделения классов?

Ответ. PointNet++ строит иерархию локальных окрестностей: выбирает центры, группирует соседние точки, извлекает локальные признаки и объединяет их на разных масштабах. Для сегментации это полезно, потому что классы часто зависят от локальной геометрии. Качество разделения классов оценивают через point accuracy, per-class IoU и mean IoU.

PointNet++ развивает PointNet за счет локальных окрестностей. Модель выбирает центры, группирует соседние точки, извлекает признаки на разных масштабах и строит иерархию локально-глобального описания формы.

Такой механизм особенно полезен для сегментации, потому что границы классов часто определяются локальной геометрией. Качество разделения оценивается через point accuracy, per-class IoU и mean IoU; допустимая ошибка выбирается с учетом прикладной задачи и цены неверной разметки.

Вопрос 5. В чем состоит применение архитектуры DGCNN для сегментации пространственной информации в трехмерном виде?

Ответ. DGCNN строит граф ближайших соседей и применяет операцию EdgeConv, которая учитывает признаки точки и ее отношений с соседями. Граф может перестраиваться в пространстве признаков, поэтому модель улавливает локальную и семантическую структуру облака. Это особенно полезно для сегментации, где важны границы и локальная форма.

DGCNN строит граф ближайших соседей и использует признаки ребер между точкой и ее окружением. Операция EdgeConv учитывает не только координаты точки, но и локальные геометрические отношения, что повышает чувствительность к форме и границам классов.

В отличие от PointNet, DGCNN явно моделирует соседство. Граф может перестраиваться в пространстве признаков, поэтому сеть постепенно переходит от геометрических отношений к более семантическим связям между точками.

Вопрос 6. Как архитектура VoteNet применяется для детекции объектов в облаках точек?

Ответ. VoteNet решает 3D-детекцию через механизм голосования: точки или их признаки голосуют за возможные центры объектов, затем votes группируются в object proposals. Далее модель предсказывает 3D bounding boxes, классы и уверенности. Текстовая схема: `point cloud -> features -> votes -> proposals -> boxes/classes`.

VoteNet решает задачу 3D-детекции через голосование точек за центры объектов. Сначала из облака извлекаются признаки, затем точки формируют votes, после чего votes группируются в object proposals.

Результат VoteNet включает 3D bounding boxes, классы объектов и уверенности. Эта архитектура отличается от сегментации тем, что не обязана размечать каждую точку, а строит компактное описание найденных объектов в трехмерной сцене.

Вопрос 7. Чем отличаются задачи классификации, сегментации и детекции объектов для пространственной информации в трехмерном виде?

Ответ. Классификация присваивает один класс всему облаку или объекту. Сегментация присваивает класс каждой точке, выделяя части или объекты внутри облака. Детекция ищет отдельные объекты и возвращает их 3D bounding boxes, классы и уверенности. Эти задачи различаются типом разметки, моделью выхода и метриками качества.

Вопрос 21. Разработать программу классификации облаков точек на основе PointNet и описать способ оценки погрешности измерительной системы.

Ответ.

PointNet обрабатывает облако точек как неупорядоченное множество. Каждая точка проходит через общие MLP-слои, после чего признаки агрегируются симметричной операцией, обычно max pooling. Благодаря этому результат не зависит от перестановки точек.

Для классификации глобальный признак подается в классификатор всего облака. Для сегментации глобальный контекст объединяется с локальными признаками точек, и модель выдает метку для каждой точки. Текстовая схема: `points -> shared MLP -> max pooling -> global feature -> class/point labels`.


Краткая цель и идея решения.
Минимальная PointNet-подобная модель классифицирует облако по агрегированным признакам точек. Погрешность измерительной системы можно оценивать как изменение точности при добавлении координатного шума.

Какие библиотеки используются и зачем.
Используются `numpy` для данных и шума, `torch` для нейросетевой модели.

```python
import numpy as np, torch
from torch import nn
rng=np.random.default_rng(421)
X=[]; y=[]
for i in range(100):
    c=i%2; X.append(rng.normal([0,0,c],0.25,(32,3))); y.append(c)
X=torch.tensor(np.array(X),dtype=torch.float32); y=torch.tensor(y)
class MiniPointNet(nn.Module):
    def __init__(self): super().__init__(); self.f=nn.Sequential(nn.Linear(3,32),nn.ReLU(),nn.Linear(32,64),nn.ReLU()); self.g=nn.Linear(64,2)
    def forward(self,x): return self.g(self.f(x).max(1).values)
model=MiniPointNet(); opt=torch.optim.Adam(model.parameters(),lr=0.01); loss_fn=nn.CrossEntropyLoss()
for _ in range(50):
    opt.zero_grad(); loss=loss_fn(model(X),y); loss.backward(); opt.step()
for noise in [0,0.1,0.2]:
    pred=model(X+noise*torch.randn_like(X)).argmax(1)
    print("noise",noise,"accuracy",float((pred==y).float().mean()))
```

Качество решения удобно проверять через accuracy, precision, recall, F1, IoU и mean IoU. Для сегментации ключевая формула имеет вид $IoU = TP/(TP+FP+FN)$, где $TP$ - верно найденные элементы класса, $FP$ - ложные срабатывания, $FN$ - пропущенные элементы.


Краткая цель и идея решения.

```python
import numpy as np
def box_iou3d(a,b):
    a=np.array(a); b=np.array(b)
    inter_min=np.maximum(a[:3],b[:3]); inter_max=np.minimum(a[3:],b[3:])
    inter=np.prod(np.maximum(0,inter_max-inter_min))
    va=np.prod(a[3:]-a[:3]); vb=np.prod(b[3:]-b[:3])
    return inter/(va+vb-inter)
```
