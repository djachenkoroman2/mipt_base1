Осенний семестр контрольные задания:
1.	Разработать программу на языке Python для «Обрезки» облака точек по ограничивающему боксу.
2.	Разработать программу на языке Python, реализующую операции разреживания облака точек.
3.	Реализовать класс для набора данных для решения задач сегментации и классификации облаков точек.

Весенний семестр контрольные задания:
1.	Разработать программу классификации облаков точек, оценить погрешности измерительной системы, использующей обученную нейросеть архитектуры PointNet.
2.	Разработать программу сегментации облака точек на основе архитектуры PoinNet++, оценить допустимую ошибку разделения классов и другие метрики.
3.	Подготовить реферат на тему «Поверхностная реконструкция на основе метода «Ball Pivoting Algorithm (BPA)»».
4.	Подготовить реферат на тему «Поверхностная реконструкция на основе метода «Delaunay Triangulation (3D)».
